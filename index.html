How It Works

This application runs the full physics and chemistry of the REACH model natively inside your browser, transforming gigabytes of atmospheric simulation data into an instantaneous client-side web engine.

1. Atmospheric Physics (Dispersion)

Instead of solving the complex Gaussian Plume equations in real-time, the meteorological physics (wind speed, direction, temperature, and pollutant decay rates over 2022) are pre-compiled. We condense these massive spatial relationships into lightweight Source-Receptor (SR) matrices. These matrices encode precisely how emissions from any one district disperse into all other 1,136 districts in South Asia.

2. Secondary Aerosol Chemistry

Once the primary dispersion is calculated via matrix multiplication, the engine runs a thermodynamic equilibrium chemistry simulation. It processes the interactions between Sulfates (SO4), Nitrates (NO3), and Ammonium (NH4) based on available Ammonia (NH3) gas, alongside Secondary Organic Aerosols (SOA). This mimics complex chemical models (like ISORROPIA) to accurately predict final PM2.5 concentrations.

3. Native Browser Architecture

To eliminate server latency and heavy WebAssembly (WASM) initialization, the Python DataFrames were converted into flat, C-contiguous Float32 Binary Arrays. When you adjust the slider, the browser fetches these raw binaries and maps them directly into memory using Native JavaScript TypedArrays. The browser's V8 Engine then executes the matrix multiplications and chemistry at native C++ speeds—meaning no server, no WASM overhead, and instant calculations!
